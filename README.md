# Molecule_Toxicity_Classification
Benchmarked Bagging Classifier, Random Forest, and Logistic Regression for predictive modeling of molecular toxicity using 5-fold cross validation and out-of-distribution compound evaluation, achieving ROC-AUC within 1% of published literature benchmarks 

Folders Decision Tree, Linear Regressor, etc. contain graphs for each models Learning Curve, Generalization Curve, and ROC.
